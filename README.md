# TOEIC 英語学習アプリ

TOEIC対策用の単語・文法・熟語学習アプリ。1つのHTMLファイルだけで動きます。

- **単語**（英→和・和→英の4択、レベル600/730/860でフィルタ）
- **文法**（Part5形式の文章穴埋め＋解説）
- **熟語・コロケーション**（句動詞、前置詞の組み合わせ）
- **ミックス**（全ジャンルからランダム出題）
- **復習**（間違えた問題だけを出題、正解でプールから消える）

学習記録はブラウザの localStorage に自動保存されます（端末ごと）。

## 使い方

`index.html` をブラウザで開くだけ。サーバーやインストールは不要です。
